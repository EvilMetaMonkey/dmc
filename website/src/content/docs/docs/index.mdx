## Start here

- **New to the project?** Read [What is dmc?](/docs/dmc/) to understand the
  model, then run the [getting started](/docs/dmc/getting-started/) steps on a
  disposable folder.
- **Reviewing this as a tester?** The
  [tester walkthrough](/docs/imported/tester-walkthrough/) is a supervised
  15-minute exercise.
- **Building an integration?** Start with
  `dmc capabilities --json --schema-version 1` and the
  [Haven integration contract](/docs/imported/haven-integration/).
